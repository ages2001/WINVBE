WVBGL32.DLL - WINVBE OpenGL ICD - license information
======================================================

WVBGL32.DLL is built from Mesa 7.8.2 (https://www.mesa3d.org/), using only
the classic core library (src/mesa/main, math, glapi, swrast, swrast_setup,
tnl, vbo, shader, shader/slang, drivers/common) and the GLSL preprocessor
and parser (src/glsl/pp, src/glsl/cl), plus the WINVBE files icd.c,
wvbdrv.c and compat.c (WINVBE project license).  No GLU, GLUT, Gallium
or demo code is included.

  - wvbdrv.c is derived from Mesa's src/mesa/drivers/windows/gdi/wmesa.c and
    src/mesa/drivers/osmesa/osmesa.c, icd.c from Mesa 6.x
    src/mesa/drivers/windows/icd/icd.c (Gregor Anich); the Mesa-derived
    parts of these files remain under the MIT license.

src/mesa/shader/program_parse.tab.c is a Bison 2.4 parser; it carries the
